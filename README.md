# Public Collections

Public-domain bodies of work, each made into its own website. Every folder here is a complete site: open it in [moss](https://mosspub.com) to read, rebuild, translate or remix it, and publish it under your own address.

| Folder | Collection | Site | Rights |
|---|---|---|---|
| `new-vienna/` | The New Vienna, 1919–1934 | https://new-vienna.mosspub.com | Pictures CC0, Public Domain Mark or public domain, each holder named in `About the sources.md` |
| `hiroshige-tokaido/` | Fifty-three Stations of the Tōkaidō | https://tokaido.mosspub.com | Prints released as CC0 by the Art Institute of Chicago; the artist died in 1858 |
| `william-blake/` | William Blake | https://www.blakesnotebook.com | Public domain; each image's source is in its page's `source:` field |
| `virginia-woolf/` | Virginia Woolf | https://virginia-woolf.mosspub.com | Public domain |
| `chautauqua-circle/` | Chautauqua Literary and Scientific Circle | https://chautauqua-circle.mosspub.com | Public domain |

`tools/` holds scripts that generated parts of a collection.

No folder carries a publishing key, so a copy cannot publish to the addresses above. moss asks for a new address the first time you publish one.
